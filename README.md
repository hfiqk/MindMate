# MindMate - 心理健康与情绪陪伴 Web 应用

## 一、 项目简介
MindMate 是一款基于大语言模型（LLM）构建的 Web 端心理健康辅助应用。项目旨在为现代高压人群提供一个兼具隐私性与趣味性的情绪记录与舒缓平台。系统不仅具备常规的情绪与生活数据追踪功能，还结合了专业心理量表与 AI 解读，并通过丰富的交互设计提升用户体验。

## 二、 核心功能
1.  **数据可视化记录**：记录每日情绪、睡眠与天气，并在 SUM 面板生成月度趋势图表分析。
2.  **AI 智能量表分析**：内置 DASS-21、GAD-7、PHQ-9 等 8 项专业心理量表，用户完成答题后，由大模型基于得分给出结构化、专业化的解读报告。
3.  **多模态解压交互**：
    *   包含 3D 线框房间交互场景。
    *   内置“抽卡”、“捏泡泡”、“揉纸团扔垃圾桶”等隐喻式物理交互解压小游戏。
4.  **AI 生活管家**：支持饮食热量估算、日常情绪对话陪伴。

## 三、 技术架构与安全设计
本项目采用前后端分离架构，所有大模型请求均由后端进行代理，保障数据与接口安全。

*   **前端**：原生 HTML / CSS / JavaScript（使用 Canvas / WebGL 实现复杂动画与 3D 场景）。
*   **后端代理**：腾讯云 CloudBase (Node.js 云函数)。
*   **大模型接入**：DeepSeek 大语言模型 API (deepseek-chat)

### 安全机制说明（核心规范）
项目严格遵守安全开发规范，杜绝密钥泄露与接口盗刷风险：
1.  **环境变量隔离**：大模型 API Key 未硬编码在任何前端或公开代码中，全部托管于云端环境变量中。
2.  **Origin 白名单校验**：云函数入口处实现了严格的跨域白名单机制，仅允许指定的部署域名发起请求，拦截非法域名的跨域调用。

## 四、 目录结构
*   **`index.html`**：前端主页面（包含所有的 UI、CSS 样式、Canvas/WebGL 动画与交互逻辑）。
*   **`ARNRE.m4a`**：系统内置的背景音乐音频文件。
*   **`cloud-functions/`**：腾讯云后端代码目录。
    *   **`index.js`**：云函数主入口，负责接收前端请求、Origin 安全校验以及代理请求大模型。
    *   **`package.json`**：云函数的依赖与配置文件。
